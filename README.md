# Codealpha-Basic-Chatbot

# CodeAlpha Internship - Task 4

## Project Name
Basic Chatbot using Python

## Description
This project is a simple rule-based chatbot.
It responds to predefined messages such as hello,
how are you, help, and bye.

## Features
- Greets the user.
- Responds to common messages.
- Provides help instructions.
- Handles unknown messages.
- Ends the conversation when the user types bye.

## Language
Python

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run: python basic_chatbot.py
